# Textures

Файлы поверхности идут комплектами:

- `*_diffuse.jpg` — цвет;
- `*_normal.jpg` — normal map (OpenGL/Three.js);
- `*_roughness.jpg` — roughness;
- `water_normal.jpg` — движение поверхности бассейна;
- `decal_*.png` — следы попаданий и кровь;
- `particle_*.png`, `sun_glow.png`, `cloud_soft.png` — отдельные sprite-изображения эффектов.

Для замены достаточно сохранить новое изображение под тем же именем. Рекомендуемый размер: 1024×1024 для основных материалов.
